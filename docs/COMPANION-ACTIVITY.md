# 主动闲聊与番茄钟（0.2.6 后续开发）

## 主动闲聊

会话设置中的开关默认关闭。启用后可设置本地时间的开始与结束时刻、两次闲聊之间的随机间隔，以及每日最多次数；时间段可以跨越午夜。后台只在桌面挂件可见、会话窗口和原有气泡均未占用、没有正在生成的回复、番茄钟未进行时尝试生成。用户发送消息后至少等待 20 分钟。未配置会话 API key、请求失败或超时时不显示伪造的角色回复；下一个随机间隔再尝试。

每次随机选择一种内容来源：最近保留的完整聊天轮次，或不带历史的新话题。只读取挂件内尚未删除的角色会话，不读取 Codex 对话、其他应用或屏幕。主动回复保存在单独的“随便聊聊”会话中，不切换用户当前选中的会话。点击提醒气泡可打开对应会话继续聊。关闭挂件窗口期间不发起主动聊天；主动闲聊不会重新显示手动隐藏的挂件。

生成闲聊时会提供当前设备本地时间，角色可按时段自然选择话题，例如晚饭；时间本身不构成用户活动证据，也不会写进历史记录。后续自动化若需更多上下文，可沿用这一请求级上下文入口，另行定义可读取的数据与操作范围。

设置保存在 `chat-activity.json`；计数、下次尝试时间、待显示提醒和番茄钟状态保存在 `chat-activity-state.json`。两者均位于原有挂件数据目录。后台请求使用当前角色人设和会话 API。最长回复是会话设置里的“主动消息最长回复”，即请求的 `max_tokens`，默认 1024，范围 1 到 32768，与前台聊天的最长回复长度分开设置；思考模型的思考过程也计入这一上限，设得太小时回复会在中途截断。主动闲聊和到点提醒都最多等 30 秒，超时后闲聊放弃，提醒改用固定文案。到点提醒在阶段结束前一分钟开始生成并暂存，到点准时显示，会话记录里的时间是显示的时刻；这一分钟里计划有变（暂停、延长、提前休息、停止或换新计划）时，暂存的文案作废、不写进会话，但这次请求照常计费。提前生成失败或被用户发起的聊天打断时，到点再生成一次。每次模型请求进入原有独立会话计费账本。

## 番茄钟

只通过角色会话提出专注分钟、休息分钟和循环次数。DeepSeek 官方接口的聊天请求向模型开放 `pomodoro_set`、`pomodoro_control`、`pomodoro_status` 三个工具；其他兼容聊天接口仍可正常纯文本聊天。模型可按要求设置，也可偶尔提出合理的调整或追问缺失信息。它请求的操作由本地白名单校验并立即执行，不弹权限窗口。白名单外操作、参数无效或阶段不符时，后台向模型返回失败结果，前端不显示技术错误；模型不能宣称操作成功。模型没有文件、网络、Codex 插件或任意代码执行工具。

`pomodoro_set` 接受 1–240 分钟专注、1–120 分钟休息、1–12 次循环，计划总长至多 24 小时；设置后立即开始。`pomodoro_control` 可暂停、继续、开始休息、开始下一轮、延长当前专注 1–60 分钟或停止。设置由用户发起的聊天触发；阶段切换还可由提醒气泡点击直接触发。主动闲聊和自动提醒生成时不提供工具。

模型知道当次请求的本地时间。深夜请求开始番茄钟时，角色可以先劝休息、建议缩短，或询问用户是否坚持；选择先询问时没有工具调用，也不会启动计时。用户确认后仍可按请求安排，是否劝阻由角色和上下文决定，不设置固定宵禁。

阶段为 `专注 → 等待开始休息 → 休息 → 等待下一轮专注`，最后一轮专注完成后结束。到点先保存新状态，再按人设生成简短提醒；生成失败时使用本地保底文案。番茄钟到点会重新显示手动隐藏的挂件。点击阶段提醒气泡即可开始休息或下一轮专注，不需要发送消息；最后一轮完成提醒点击后只关闭。关闭气泡上的叉号只隐藏提醒，不推进计时。仍可通过聊天暂停、延长或结束。每条可点击提醒绑定计划、轮次、阶段和唯一提醒标识；重复点击、已延长阶段的旧提醒或已替换计划的提醒均不推进。点击本身不请求模型、不增加会话消费。

菜单内的“番茄钟提醒音效”与“任务结束音效”“审批提醒音效”放在一起，默认开启，可独立关闭或选择内置音效组、已导入的自定义音频片段；仍受总音效开关控制。每条到点提醒在首次弹出时播放一次，轮询和打开历史不会重复播放。角色旁显示阶段、轮次和剩余时间；时钟以保存的绝对截止时间为准，电脑睡眠或应用重启后不会从头计时。恢复时只产生当前到期阶段的一条提醒。

阶段规则、数值范围与提醒身份集中在 `runtime/chat/pomodoro.mjs`（只处理状态值，不读写文件、不启动计时器）；`runtime/chat/activity.mjs` 负责保存状态、按时触发和提醒队列。状态或设置文件损坏时按无计划和默认设置处理，下一次保存会覆盖它，会话功能不受影响。倒计时以后台返回的剩余秒数为准，界面只计算距上次获取经过的时间。

流式工具调用经过 `runtime/chat/provider.mjs` 汇集，`runtime/chat/reply.mjs` 将白名单执行结果作为工具消息交还模型，最多进行两轮工具调用再生成最终文字。后台回复生成完毕后先判断是否仍然有效（番茄钟阶段未变、主动闲聊时番茄钟未开始），有效才写入会话历史并显示提醒；作废的回复仍计入会话计费。每一轮模型请求分别记账，原有 30 天消费显示包含这些请求以及主动闲聊、角色计时提醒。没有模型用量的请求仍标记为待核；本地保底提醒不计模型费用。

`GET /api/chat/activity` 返回番茄钟状态和待显示提醒；`GET/PUT /api/chat/activity/settings` 管理主动闲聊配置；`POST /api/chat/activity/ack` 确认提醒已显示；`POST /api/chat/activity/advance` 校验提醒标识并开始下一段；`POST /api/chat/activity/presence` 告知后台当前窗口是否正被用户使用。UI 轮询本地进程接口，无外部网页或额外监听端口。

## 验证

`tests/chat-activity.test.mjs` 覆盖流式工具调用、白名单拒绝、每轮计费、定时状态恢复、提醒点击、重复与过期点击拦截、主动闲聊时间与次数限制、历史/新话题分支和独立会话。`tests/desktop-fixture.mjs` 使用注入时钟覆盖真实 Electron 中提醒点击启动休息与专注、单次播放提示音、音效关闭与自定义片段持久化，另覆盖模型设置番茄钟、倒计时不被会话窗口遮挡、主动闲聊设置保存及进程重启恢复；模型和余额均为合成响应，不消耗实际额度。
