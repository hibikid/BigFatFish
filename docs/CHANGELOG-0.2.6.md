# 0.2.6 本地版本

基于 `d035ad0` 的用量请求与展示适配拆分，固定当前桌面挂件、计费与角色会话功能。源码标签为 `codex-v0.2.6`；这是本地可回退版本，未推送或发布安装包。

## 新增与调整

- 角色会话：右键角色或 macOS 全局 Ctrl+0 打开已聚焦的输入框；支持自定义接口、模型、API key、人设、回复长度和流式输出。回复气泡随内容增长，点击任意位置收起，展开记录恢复最后一条回复。
- 会话列表：新建、切换、继续和单独删除会话；旧单会话历史迁移并备份。每个会话的上下文独立，删除会话保留计费记录。
- DeepSeek 会话计费：独立保存当前密钥近 30 天本地用量，恢复可归属的旧聊天记录；显示估算上下限的平均值并保留两位小数，同时读取官方账号余额。此估算不等于官网账号总消费。
- 复核订阅气泡文字：当前保存的字号没有溢出；默认大字号和旧普通气泡样式在长额度文字下仍可能溢出，详见 [复核记录](USAGE-DISPLAY.md#订阅气泡复核)。

## 验证与回退

`npm test`、`npm run check` 和 `npm run test:desktop` 使用合成数据验证，不消耗真实模型额度。macOS 桌面测试覆盖初次启动与重启、会话列表、快捷键、流式回复、计费与审批提醒。Windows 桌面尚未做本版实机验证。

可用 `git show codex-v0.2.6` 查看本版提交，或从此标签建立独立工作区。Git 标签只覆盖源码；`~/.codex/whale-widget` 内的会话历史、密钥引用和计费账本需要单独备份。旧版程序可能不理解已迁移的多会话历史，回退前应先备份数据目录。

实现和限制详见 [角色会话](CHAT.md)、[用量请求与展示适配](USAGE-DISPLAY.md)、[0.2.5 基线与回退](BASELINE-0.2.5.md)。
