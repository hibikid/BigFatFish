# 0.2.5 开发基线

本次把 `codex-v0.2.4`（`8de181a`）之后的本地开发成果与行为测试整理为可回退基线。标签为 `codex-v0.2.5-baseline`，属于本地开发快照，不代表已发布或完成全部平台回归。

## 已有开发成果

- macOS 与 Windows 默认自由桌面模式：独立启动、保持置顶，Codex 窗口状态不再决定挂件的显示与生命周期；保留旧跟随模式兼容路径。
- 多 API 数据源：按会话中的 `model_provider` 选择配置，支持同源查询链接、TOML 请求头、独立记账和总览；主轮汇总子任务用量，避免再次累加子任务。
- macOS 直接输入密钥：通过 Electron `safeStorage` 加密后存放在本地文件，公开配置与界面响应不返回密钥；也可使用环境变量。
- Codex 订阅额度：读取会话中 5 小时 / 7 天窗口，显示剩余百分比；API 会话或过期快照回退到 API 余额。完成提示可展示本轮订阅快照。
- 审批提醒：本地 hook 仅传递权限请求事件标记；气泡持续显示，点击气泡或鲸鱼关闭；独立音效开关，支持预设、音效组与自定义音频。
- macOS 启动器 `.app` 与图标、Node 发现及 npm / pnpm 安装兼容、安装冷启动等待与诊断信息改进。

## 基线整理新增

- 纳入原有 5 个测试文件，补充订阅额度、多源主子任务结算、重启恢复、待记账金额、配置保护和音效持久化测试。
- 恢复可执行的 Electron 隔离测试入口，包含首次启动与完整进程重启；保留截图和 JSON 结果。
- 修复回归测试发现的异常订阅百分比校验问题：空值、空字符串及布尔值不再转换为有效额度。
- 添加 `npm test`、`npm run test:desktop`、`npm run check`，更新测试入口和过时的审批提醒说明。
- 补充验证范围与源码回退步骤；本次没有拆分模块或添加聊天功能。
