# 额度由后台额度簿统一汇总，账户是密钥唯一的存放处

2026-10-05 决定：大肥鱼显示的四类额度（Codex 订阅、Claude 订阅、Codex 用的 API、大肥鱼自己用的 DeepSeek）由后台的额度簿统一汇总，由它决定挂件显示哪个账户，前端只负责渲染。此前显示逻辑分在后台判断订阅、后台选 API 来源、前端切换来源和展示判定四处，5 小时 / 7 天窗口的校验写了四遍，同一个 DeepSeek 密钥被两处各查一次余额，API 设置要手填配置文件路径，用量面板没人看得懂。

- 额度账户是唯一的模型：订阅账户与 API 账户。一个 API 账户是一个地址加一个密钥，可以同时给 Codex 的 provider 和大肥鱼用；同地址同密钥只算一个账户。
- 密钥只在额度管理里填写，存入钥匙串；会话设置只选账户，不再有自己的密钥。
- 大肥鱼的所有模型请求（会话、主动闲聊、番茄钟提醒，以及以后的智能功能）都经过“大肥鱼账户”，默认 DeepSeek 官方。以后的新功能不另设密钥，也不悄悄使用 Codex 或 Claude 的额度。
- 提醒由额度簿判断，前端只显示。
- 不变：`/dsh-whale/*` 地址、`dshw-*` 本地键名、账本与订阅快照的文件格式。`api-settings.json` 和 `chat-settings.json` 原样保留，回退到旧版本仍能用。

以后若要在前端判断显示哪个额度，或给新的智能功能单独配置密钥，都与这条决定相反，应先重新讨论。实现与口径见 [额度管理](../QUOTA.md)。
