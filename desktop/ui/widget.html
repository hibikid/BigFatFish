小鲸鱼独立常驻桌面；当前余额与多个 Codex API 消耗可分别记录。

多个 Codex API 数据源（总消耗统计）

添加 work.config.toml、play.config.toml 等独立配置。小鲸鱼用日志里的 model_provider 归类会话，不读取聊天内容。新来源默认使用 macOS 钥匙串；直接输入密钥时，设置只保存钥匙串加密后的数据，不保存明文。

查询链接留空时以 TOML 的 base_url 自动探测；填写时直接查询该完整链接。认证默认使用 Bearer 密钥并合并 TOML 的 http_headers。环境变量方式仅作兼容，必须对小鲸鱼的 LaunchAgent 可见；任一密钥不可用时仍统计 Token，但无法查询该来源余额或金额。

每轮费用估算（可选）

未配置价格时，显示本轮期间观测到的 API 扣费；它可能包含同密钥的其他调用。配置价格后，按 Codex token 记录估算。价格单位是每百万 token，币种使用上方设置。

仅处理用量与任务状态，不发送聊天内容。ChatGPT 订阅对话不属于此 API 账单，也不提供本机 Codex 会话用量。
